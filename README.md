# Civ Pro 215A Jeopardy

Classroom Jeopardy game for Civil Procedure 215A (SLO Lab), Fall 2026, Prof. Cummins.

Six categories (personal jurisdiction, notice and service, subject matter jurisdiction, venue/transfer/FNC, Erie, pleading), two random Daily Doubles per game, team scoring, and Final Jeopardy with wagers and a 30-second clock.

Open `index.html` in a browser to play. Space reveals a response; Esc returns to the board.
